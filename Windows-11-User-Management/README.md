# Windows 11 User Management Lab

## Objective
Practice basic IT support tasks involving local user accounts, password management, and file permissions in a Windows 11 virtual machine.

## Environment
- Operating System: Windows 11 Home
- Virtualization: Oracle VirtualBox
- Virtual Machine: IT-LAB-WIN11

## Tasks Completed
- Created a local user account named HelpdeskUser.
- Tested logging into the HelpdeskUser account.
- Changed the user's password.
- Verified the user's account permissions.
- Created a Helpdesk-Test folder.
- Created a test text file.
- Checked the file's security permissions.
- Modified and successfully saved the test file.

## What I Learned
This lab gave me hands-on practice with basic Windows user account management and file permissions. I learned how to create and test a local user account, change a password, and view the permissions assigned to a user.

## Troubleshooting
During the Windows 11 virtual machine setup, I had to make sure the Windows 11 ISO was properly mounted in VirtualBox before the virtual machine could boot into Windows Setup.

## Skills Practiced
- Windows user account management
- Password management
- File and folder permissions
- Basic Windows troubleshooting
- Virtualization
- Technical documentation
